# Version changes

## v4.0.1 — stable

Frozen classifier source snapshot from production. Includes near-uniform screening,
effective dimensional routing, reflection/extinction and peak alignment, geometry
and topology checks, canonical names, and aligned convergence/free-energy gates.
Historical internal version strings remain unchanged for output compatibility.

## v4.0.2 — experimental

Adds axis and mixed-basis supercell handling with reconstruction checks; bounded
conventional-cell searches; weak-peak, layer variation and sampling diagnostics;
particle-center arrangement, extinction, network topology, and approximate SC
supercell checks. Single-layer comparisons can remain unavailable. Input quality
and unresolved conflicts can still require review; no sample-ID label overrides.

This is a snapshot of existing code, not a new algorithm release or deployment.
